# Harness Core Beliefs

- `AGENTS.md` is a directory, not a warehouse.
- Repo-local, versioned artifacts count as agent-visible truth.
- Refactor stage truth lives in `docs/refactor/**`, not in shims or summaries.
- After each atomic change, commit immediately with a Chinese commit message.
- Repeated review feedback should graduate into documentation or an automated check.
- Generated files are script-owned and must not be hand-edited.
- Current-focus docs should explain what to do next, not reprint the whole project history.
- Historical checkpoints may remain useful, but they are never equal to current authority by default.
